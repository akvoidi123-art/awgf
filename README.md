# AreaMiner (клиентский мод, Fabric 26.1.2)

Два независимых режима + самооборона. Работает только на клиенте —
на сервере ничего ставить не нужно (мод просто двигает персонажа,
поворачивает камеру и жмёт кнопки, как обычный игрок).

## Режим 1 — копание области

1. Возьмите в руку **деревянную мотыгу**. ЛКМ по блоку — точка 1, ПКМ — точка 2.
2. Встаньте на поверхность у верхней границы области.
3. `/areaminer start` или кнопка (Настройки → Управление → AreaMiner → "Старт/стоп автокопания").
4. Бот идёт "змейкой" по столбцам: в каждой точке сразу выкапывает весь столбец
   сверху донизу стоя на месте (без прыжков), потом шагает дальше. Если под
   следующей клеткой пустота — сам подставит блок-мостик (cobblestone/dirt/
   netherrack/stone из хотбара).

## Режим 2 — замена блоков

1. Возьмите в руку **деревянную лопату** — это отдельная палочка выделения
   для области замены (независима от области копания, можно держать обе
   выделенными одновременно).
2. Назначьте блоки:
   - Возьмите в руку блок, который нужно **заменить** (например, камень),
     нажмите кнопку **"Заменяемый блок"**.
   - Возьмите в руку блок, **на который менять** (например, землю),
     нажмите кнопку **"Блок для замены"**.
   (Обе кнопки — в Настройки → Управление → AreaMiner, по умолчанию не назначены.)
3. `/areaminer replace start` или кнопка **"Старт/стоп замены блоков"**.
4. Бот идёт по области и **ломает только назначенный блок**, остальные не трогает;
   на его месте сразу ставит блок замены из хотбара. Если рядом нет твёрдой
   опоры или в хотбаре кончился блок замены — остановится с сообщением.

Пока у режима заданы обе точки — область подсвечивается частицами:
жёлто-белые (END_ROD) — область копания, зелёные искры — область замены.

## Самооборона (не обязательно)

`/areaminer combat on` — если рядом (в 6 блоках) появляется враждебный моб,
бот на время прерывает текущую работу, поворачивается и отбивается, затем
продолжает с того же места. `/areaminer combat off` — выключить (по умолчанию
выключено).

## Все команды

```
/areaminer start | stop | clear | wand | status
/areaminer replace start | stop | clear | wand
/areaminer combat on | off
```

`wand` — назначить палочкой выделения (для копания/замены) предмет, который
сейчас у вас в руке, если не хотите использовать мотыгу/лопату.

## Ограничения

- Копание и замена не могут работать одновременно — сначала остановите одно,
  чтобы запустить другое.
- Действует обычная дальность взаимодействия (~4.5–6 блоков), поэтому бот
  всегда работает с соседним столбцом, находясь рядом с ним, а не издалека.
- Останавливается сам при: лаве рядом, здоровье ниже 4 сердец, отсутствии
  подходящего блока/опоры, если застрял дольше ~30 секунд, или если область
  больше 10 000 клеток по площади.
- Многие серверы запрещают автоматизацию — используйте там, где это разрешено.

## Сборка

```bash
./gradlew build
```
Готовый jar — `build/libs/areaminer-1.0.0.jar`. Либо через GitHub Actions
(workflow уже в `.github/workflows/build.yml`) — jar появится в Artifacts.

Установка: jar + **Fabric API** для 26.1.2 в папку `mods` клиента.
